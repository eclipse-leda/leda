Full qualified VSS Path: Vehicle.Powertrain.ElectricMotor.FrontRight
Description: Electric Motor specific data.
Comment: Instance Front to be used if the vehicle has a motor located at the front of the vehicle, serving front and possibly also rear axle. Instance Rear to be used if the vehicle has a motor located at the rear of the vehicle, serving rear and possiblsy also front axle. Instances with Left/Right intended to be used if vehicle has separate motors for left and right side.

Signal Information

The vehicle signal Vehicle.Powertrain.ElectricMotor.FrontRight is a Branch.

Children

This vehicle signal is a branch or structure and thus has sub-pages:

  • Vehicle.Powertrain.ElectricMotor.FrontRight.EngineCode (Engine code designation, as specified by vehicle manufacturer.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.EngineCoolant (Signals related to the engine coolant (if applicable).)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.MaxPower (Peak power, in kilowatts, that motor(s) can generate.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.MaxRegenPower (Peak regen/brake power, in kilowatts, that motor(s) can generate.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.MaxRegenTorque (Peak regen/brake torque, in newton meter, that the motor(s) can generate.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.MaxTorque (Peak power, in newton meter, that the motor(s) can generate.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.Power (Current motor power output. Negative values indicate regen mode.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.Speed (Motor rotational speed measured as rotations per minute. Negative values indicate reverse driving mode.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.Temperature (Motor temperature.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.TimeInUse (Accumulated time during engine lifetime when the vehicule state’s is ‘READY’.)
  • Vehicle.Powertrain.ElectricMotor.FrontRight.Torque (Current motor torque. Negative values indicate regen mode.)
